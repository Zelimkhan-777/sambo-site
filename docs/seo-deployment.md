# SEO: настройка публикации

## Обязательная переменная окружения

На production-хостинге укажите публичный адрес сайта без завершающего слеша:

```text
VITE_SITE_URL=https://ваш-домен.ru
```

Без этой переменной приложение в браузере определяет canonical по текущему домену,
но production-сборка намеренно не создаёт sitemap с неподтверждённым адресом.

## Что создаётся при сборке

Команда `npm run build`:

- добавляет отдельные HTML-входы с метаданными для основных маршрутов;
- при доступности Directus добавляет входы для опубликованных новостей и видео;
- создаёт `robots.txt`;
- при наличии `VITE_SITE_URL` создаёт `sitemap.xml` с абсолютными URL;
- создаёт `404.html` с директивой `noindex`.

## Требования к хостингу

Хостинг должен отдавать существующие `*/index.html` и направлять остальные
маршруты SPA на корневой `index.html`. Ответ реальной отсутствующей страницы
должен иметь HTTP-статус 404, а не 200.

После публикации проверьте доступность:

```text
https://ваш-домен.ru/robots.txt
https://ваш-домен.ru/sitemap.xml
```

Затем добавьте sitemap в панели вебмастеров используемых поисковых систем.
Коды подтверждения владения доменом добавляются отдельно после их получения.
